How the score works

ShipCheck starts at 100 and subtracts a penalty for every problem it finds. Each problem is capped, so no single broken area can zero the score on its own. The model is deterministic — the same release always gets the same score.

AreaWhat countsPenalty
Tests & CICI failing / pending / no status found15 / 5 / 8
BugsOpen critical / blocker bugs8 each, max 32
Pull RequestsPRs open > 14 days; PRs with no review5 / 4 each, max 36
DocumentationMissing README / CHANGELOG / release notes6 / 4 / 2
Release HygieneNo release or tag; no commits in 30 days; no rollback plan8 / 6 / 6

90–100 · READY — Ship it 70–89 · CAUTION — Ship with care 50–69 · HOLD — Fix blockers first 0–49 · NO-GO — Do not ship

A signal that could not be checked (for example, the rollback plan is not visible from the GitHub API) is shown as “not checked” — it adds no penalty and is reported, never silently ignored.
